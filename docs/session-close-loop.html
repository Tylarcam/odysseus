Cursor · Odysseus · AgentMemory

Session close-out loop

One command when a chat is done: catalog the session, write a continuity recap, save durable memory, and land a note in Odysseus — so the next agent can resume without rediscovery.

/end-chat

The loop

1

cursor-session-catalog

Resolve this chat’s session ID from agent-transcripts, plus resume command and transcript path.

skill: cursor-session-catalog
2

cursor-end-session

Synthesize goals, changes, blockers, artifacts, and a short next-session checklist into a recap markdown body.

skill: cursor-end-session
3

AgentMemory

Persist one dense paragraph via MCP memory_save (and optional localhost:40001/remember). Failures are non-fatal.

MCP: user-agentmemory
4

create-note2ody

Write the recap to Odysseus as a note (label: cursor) and return note_id + open_url.

skill: create-note2ody

How to run

Slash command (preferred)

In any Cursor agent chat, type:

/end-chat

Runs the full loop once. Lives at ~/.cursor/commands/end-chat.md.

Natural language

Also works if you say:

  • “end chat”
  • “close session loop”
  • “wrap up and save everywhere”

What you get back

SurfaceArtifactWhy
Catalog Session UUID + agent --resume Reopen this exact chat later
AgentMemory Saved insight (workflow / fact) Future agents can memory_recall
Odysseus Note titled Cursor session recap — DATE — topic Human-readable continuity in HQ

Requirements

  • ODYSSEUS_URL + ODYSSEUS_API_TOKEN in ~/code/odysseus/.env (token needs todos:write)
  • MCP server user-agentmemory connected (optional but recommended)
  • Optional: archivist remember API on http://localhost:40001/remember
Non-fatal steps: AgentMemory and /remember may fail if services are down. The Odysseus note is the hard requirement — if that 403s, enable write scope in Odysseus Settings.
